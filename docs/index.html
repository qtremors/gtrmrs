YOURS TO USE LOCALLY

A small addition.
A useful habit.

Clone the source. Install locally.
Start with whichever command you need.

Python 3.11+ · Git for Git-aware operations
FROM SOURCE
  1. git clone https://github.com/qtremors/gtrmrs.git
  2. cd gtrmrs
  3. python -m pip install -e .

Local source install. No PyPI package.

Prefer to skip installation?

From the cloned source directory:

python -m gtrmrs.cli --help

THE SHORT VERSION

Will it change my files?

Scans are read-only. Migration writes a destination copy. Dependency updates edit build files when requested. Storage deletion requires --clean --apply; stop builds and other writers first.

Where are the details and limitations?

The command guide covers filtering, supported formats, network requests, update limits and cleanup rules. Start with a preview before applying changes.
