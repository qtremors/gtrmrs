# rtree

Show a directory tree or a flat file list with Git-aware filtering.

```sh
rtree
rtree --depth 2
rtree --flat
rtree --raw
rtree --out tree.txt
rtree --no-color
```

Output paths use the shell working directory. `--ascii` removes icons while
retaining Unicode tree connectors.
